# Atividade 06-02
Este é o repositório que armazena a tarefa solicitada no dia 06/02. Todos os arquivos necessários à execução já foram criados, de modo que basta seguir as instruções abaixo para executá-lo em seu dispositivo.


## Como Usar
1. Para acessar a atividade armazenada, clone este repositório para seu dispositivo executando o seguinte comando no terminal de um ambiente adequado, como o VS Code, após criar um repositório local: git clone https://github.com/nivaldojunior037/Atividade-06-02-EmbarcaTech

2. Após isso, abra a pasta que contém os arquivos clonados em um ambiente como o VS Code.

ATENÇÃO!!! Antes de compilar seu código, escolha se utilizará a BitDogLab ou o Wokwi!

3. Caso vá utilizar o Wokwi, mantenha o código como você o obteve do repositório. Em caso contrário, vá até o arquivo AtvServomotor.c e, na linha 8 do código, altere a expressão "#define ServPin 22" para "#define ServPin 12". Isso permitirá o uso adequado na BitDogLab.

4. Em seguida, compile o código existente para que os demais arquivos necessários sejam criados em seu dispositivo.

5. Ao fim da compilação, será gerado um arquivo .uf2 na pasta build do seu repositório. Esse arquivo deve ser copiado para a BitDogLab em modo BOOTSEL para que ele seja corretamente executado, caso seja essa sua opção. Em caso oposto, basta iniciar a simulação usando o ambiente Wokwi integrado ao VS Code.
